Política de Privacidade — gastos-sync

O gastos-sync é uma ferramenta de uso pessoal, operada pelo próprio titular da conta Google conectada, para consolidar gastos a partir de e-mails de notificação de bancos.

Dados acessados

Com a permissão gmail.modify, o app lê apenas e-mails que correspondem a filtros de remetentes e assuntos financeiros (compras, Pix, faturas) e aplica neles o rótulo gastos-sync/processado. Nenhum e-mail é enviado, apagado ou compartilhado.

Uso dos dados

O conteúdo desses e-mails é enviado à API do Google Gemini apenas para extrair data, valor, estabelecimento, conta/cartão e categoria. Os dados extraídos ficam armazenados em um banco de dados privado (Supabase) acessível somente pelo titular, por meio de painel protegido por senha.

Compartilhamento

Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade. O uso de dados recebidos das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado.

Revogação e exclusão

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os dados armazenados podem ser excluídos pelo painel ou diretamente no banco de dados.
